# สมุดบันทึกหลังสอน

ระบบบันทึกผลหลังแผนการจัดการเรียนรู้ ระดับอนุบาล ประถมศึกษา และมัธยมศึกษา
**พัฒนาระบบโดย ครูซอสสอนสังคม**

- **หน้าเว็บ:** HTML/CSS/JS ไม่ต้อง build ฝากไว้บน Vercel
- **ฐานข้อมูล:** Firebase Firestore
- **การเข้าสู่ระบบ:**
  - ครูและแอดมินโรงเรียนใช้ชื่อผู้ใช้และรหัสผ่านที่โรงเรียนกำหนด
  - แอดมินหลักใช้บัญชี Google ผ่านทางเข้าลับ คือแตะชื่อ "สมุดบันทึกหลังสอน" บนหน้าแรก 5 ครั้งติดกัน
- **การจัดการบัญชี:** สร้างบัญชี รีเซ็ตรหัสผ่าน ปิดใช้งาน และเปลี่ยนสิทธิ์ ทำผ่าน `api/admin.js` ซึ่งเป็นฟังก์ชันบน Vercel ใช้ฟรี

```
index.html              หน้าเว็บ
css/style.css           หน้าตา โทนแดง-ทอง (รองรับมือถือ แท็บเล็ต คอมพิวเตอร์)
js/app.js               การทำงานทั้งหมด
js/firebase-config.js   ค่าเชื่อมต่อ Firebase                 ← ต้องแก้
api/admin.js            API จัดการบัญชี (รันบน Vercel)
firestore.rules         กฎความปลอดภัยของฐานข้อมูล            ← ต้องวางใน Firebase
package.json            บอก Vercel ให้ติดตั้ง firebase-admin
vercel.json             ตั้งค่า Vercel
```

## ติดตั้ง (ประมาณ 30 นาที)

### 1. สร้างโปรเจกต์ Firebase
1. ไปที่ https://console.firebase.google.com แล้วกด **Create a project**
2. ตั้งชื่อ เช่น `teaching-log-school` ส่วน Google Analytics จะปิดก็ได้

### 2. เปิดวิธีเข้าสู่ระบบ 2 แบบ
ไปที่ **Build → Authentication → Get started → แท็บ Sign-in method** แล้วเปิด 2 รายการนี้:
- **Email/Password:** กด Enable แล้ว Save ส่วนนี้ใช้กับครูและแอดมินโรงเรียน ระบบแปลงชื่อผู้ใช้เป็นบัญชีให้เอง ไม่มีการส่งอีเมลจริง
- **Google:** กด Enable ใส่อีเมลติดต่อ แล้ว Save ส่วนนี้ใช้กับแอดมินหลัก

### 3. สร้างฐานข้อมูล Firestore
1. ไปที่ **Build → Firestore Database → Create database**
2. Location เลือก **asia-southeast1 (Singapore)** ซึ่งเลือกแล้วเปลี่ยนภายหลังไม่ได้
3. เลือก **Start in production mode**
4. ไปที่แท็บ **Rules** ลบข้อความเดิมทั้งหมด วางเนื้อหาไฟล์ `firestore.rules` แล้วกด **Publish**

### 4. ใส่ค่าเชื่อมต่อในโค้ด
1. กด ⚙ **Project settings** → ส่วน **Your apps** → กดไอคอน **</>** (Web) → ตั้งชื่อ → **Register app**
2. คัดลอกค่าใน `firebaseConfig` ไปแทนค่าตัวอย่างในไฟล์ `js/firebase-config.js`

> ค่า firebaseConfig ไม่ใช่รหัสลับ อยู่ในหน้าเว็บได้ตามปกติ

### 5. สร้างกุญแจ Service account (สำหรับ API จัดการบัญชี)
1. ⚙ **Project settings** → แท็บ **Service accounts** → กด **Generate new private key** → **Generate key**
2. จะได้ไฟล์ `.json` มา 1 ไฟล์ **ไฟล์นี้เป็นความลับ** ห้ามอัปโหลดขึ้น GitHub และห้ามส่งต่อให้ใคร ขั้นตอนที่ 7 จะนำเนื้อหาไปวางใน Vercel แทน

### 6. นำโค้ดขึ้น GitHub
- **ไม่ถนัดใช้ git:** สร้าง repository ใหม่ที่ https://github.com/new (เลือก **Private**) → กด **uploading an existing file** → ลากไฟล์และโฟลเดอร์ทั้งหมดเข้าไป **ยกเว้นไฟล์กุญแจ .json** → กด Commit
- **ใช้ git:**
  ```bash
  git init && git add . && git commit -m "สมุดบันทึกหลังสอน"
  git branch -M main
  git remote add origin https://github.com/<ชื่อบัญชี>/<ชื่อ-repo>.git
  git push -u origin main
  ```

### 7. Deploy บน Vercel
1. ไปที่ https://vercel.com/new เข้าสู่ระบบด้วย GitHub แล้วกด **Import** ที่ repository
2. **Framework Preset:** เลือก **Other** ไม่ต้องตั้ง Build Command
3. เปิดส่วน **Environment Variables** แล้วเพิ่ม 2 ค่านี้:

   | Name | Value |
   |---|---|
   | `FIREBASE_SERVICE_ACCOUNT` | เปิดไฟล์กุญแจ .json จากขั้นที่ 5 ด้วย Notepad คัดลอก**ทั้งไฟล์**มาวาง |
   | `SUPERADMIN_EMAIL` | อีเมล Gmail ของแอดมินหลัก เช่น `yourname@gmail.com` |

4. กด **Deploy** จะได้ที่อยู่เว็บ เช่น `https://teaching-log-school.vercel.app`

หลังจากนี้ แก้โค้ดแล้ว push ขึ้น GitHub เมื่อไหร่ Vercel จะ deploy ให้ใหม่อัตโนมัติ ถ้าแก้ Environment Variables ต้องกด **Redeploy** ด้วย

### 8. อนุญาตโดเมนของเว็บใน Firebase
Firebase → **Authentication → Settings → Authorized domains → Add domain** → ใส่ `teaching-log-school.vercel.app` (ไม่ต้องมี https://)

### 9. เข้าสู่ระบบครั้งแรกในฐานะแอดมินหลัก
1. เปิดเว็บ แล้ว**แตะชื่อ "สมุดบันทึกหลังสอน" 5 ครั้งติดกัน** จะมีปุ่ม "เข้าสู่ระบบด้วยบัญชี Google" โผล่ขึ้นมา
2. เลือกบัญชี Gmail ที่ตั้งไว้ใน `SUPERADMIN_EMAIL` ระบบจะสร้างบัญชีแอดมินหลักให้เอง
3. ไปที่ **ตั้งค่าโรงเรียน** ใส่ชื่อโรงเรียน และตรวจวันเปิดภาคเรียน
4. ไปที่ **ครูและผู้ดูแล → สร้างบัญชีใหม่** สร้างบัญชีแอดมินโรงเรียน เช่น ผู้อำนวยการ และหัวหน้างานวิชาการ แล้วเลือกสิทธิ์ "แอดมินโรงเรียน"
5. แอดมินโรงเรียนสร้างบัญชีครูต่อได้เอง แล้วแจ้งชื่อผู้ใช้และรหัสผ่านให้ครูแต่ละคน

### 10. ครูเริ่มใช้งาน
1. ครูเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านที่ได้รับ แล้วเปลี่ยนรหัสผ่านที่ **บัญชีของฉัน**
2. วาดลายเซ็นที่ **บัญชีของฉัน**
3. กำหนด **วิชาที่สอน** ของภาคเรียนนี้
4. เริ่ม **เขียนบันทึก** ได้เลย

## ข้อควรรู้

- **ภาคเรียนและปีการศึกษา** เปลี่ยนอัตโนมัติตามวันที่ ค่าเริ่มต้นคือภาคเรียนที่ 1 เริ่ม 16 พ.ค. และภาคเรียนที่ 2 เริ่ม 1 พ.ย. แก้ได้ที่ "ตั้งค่าโรงเรียน" ข้อมูลภาคเรียนเก่าเปิดดูและดาวน์โหลดได้ตลอด แต่แก้ไขไม่ได้
- **ลืมรหัสผ่าน:** แอดมินโรงเรียนกด "รีเซ็ตรหัสผ่าน" ที่หน้า "ครูและผู้ดูแล" ระบบจะแสดงรหัสใหม่ให้แจ้งครู
- **ครูย้ายหรือลาออก:** กด "ปิดใช้งาน" ไม่ต้องลบ บันทึกเดิมยังอยู่ครบ
- **เปิดลิงก์จาก LINE:** ระบบพยายามเปิดในเบราว์เซอร์ปกติให้อัตโนมัติ เพราะ Google ไม่อนุญาตให้เข้าสู่ระบบในเบราว์เซอร์ของ LINE เรื่องนี้มีผลกับปุ่ม Google ของแอดมินหลักเท่านั้น
- **PDF:** ทุกเอกสารเปิดดูตัวอย่างก่อนดาวน์โหลดได้ ขนาดกระดาษเป็น A4 ตามแบบฟอร์มของโรงเรียน
- **อินเทอร์เน็ตไม่ดี:** บันทึกจะเก็บไว้ในเครื่องก่อน แล้วส่งขึ้นระบบเองเมื่อกลับมาออนไลน์ เมื่อส่งสำเร็จจะขึ้นข้อความ "บันทึกขึ้นระบบแล้ว"
- **ค่าใช้จ่าย:** ใช้แผนฟรีได้ทั้งคู่
  - Firebase (Spark) อ่านได้ 50,000 ครั้งต่อวัน เขียน 20,000 ครั้งต่อวัน พื้นที่ 1 GB
  - Vercel (Hobby)
  - หน้ารายการโหลดเฉพาะภาคเรียนที่เลือก เพื่อประหยัดโควตา
- **สำรองข้อมูล:** ปลายภาคเรียน ให้กดดาวน์โหลด CSV และ PDF รวมเล่มเก็บไว้ใน Google Drive ของโรงเรียน

## ทดสอบบนเครื่องตัวเอง
```bash
npm i -g vercel
vercel dev
```
`vercel dev` รันทั้งหน้าเว็บและ `/api/admin` ต้องตั้งค่า Environment Variables ในไฟล์ `.env` ก่อน ไฟล์นี้อยู่ใน .gitignore แล้ว
